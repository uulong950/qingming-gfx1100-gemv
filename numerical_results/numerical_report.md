# FP32 GEMV numerical analysis

This report is generated by `numerical/fp32_accuracy.cpp`.

## Method

- FP64 host reference using the exact FP32 operands.
- Tolerance: `atol=1e-4`, `rtol=1e-4`.
- `eta/u = (|error| / sum |a_k x_k|) / 2^-24`.
- Three repeated launches are compared bitwise.
- Backends: native gfx1100 GEMV, rocBLAS SGEMV, hipBLASLt GEMM-as-GEMV.

## Experiments

1. Baseline patterns across N = 256, 1024, 4096, 16384, 65536.
2. Cancellation-distance tomography at N = 65536 with exact zero->nonzero detection.
3. Adaptive 8K-16K breakpoint zoom: 512 -> 64 -> 8 element resolution.
4. hipBLASLt restored-solution and heuristic accuracy sweep.
5. Optional ISA capture and topology correlation via `tools/`.

Native workspace is explicitly zero-initialized before every repeated launch.

The CSV files in this directory are the authoritative machine-readable results.
